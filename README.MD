# Zombie Cowboys

> [!IMPORTANT]
> **The repository on GitHub is a mirror**
> The source is stored on [my personal Gitea server](https://git.mmmaellon.com/MMMaellon/ZombieCowboys)

Zombie Cowboys is a VRChat game that I'm open-sourcing so it can hopefully serve as a learning resource.
I plan to document every step of the world's development so even complete beginners can follow along. See the [Wiki](https://git.mmmaellon.com/MMMaellon/ZombieCowboys/wiki).
