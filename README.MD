# Zombie Cowboys

A co-operative PvE game for VRChat.

Defend the town against **ZOMBIE COWBOYS** with your trusty **whip** and **six shooter**.
Buy upgrades, build defenses, and find a way to undo the curse that keeps bringing the dead back to life.

## [Project Wiki](https://git.mmmaellon.com/MMMaellon/ZombieCowboys/wiki)

I plan to document every step of the dev process so people interested in learning VRChat world creation can follow along and use this as a tutorial.
I'll try to explain advanced concepts and share helpful tips as I build this project from scratch.
